# Пинбол Марни

Браузерный пинбол по мотивам мини-игры из таверны Делесии в Crimson Desert:
одна попытка — один шар, заряжаемый запуск, жетоны Марни и лавка призов Джаспера.

**Играть:** https://grandowner.github.io/marni-pinball/

## Управление

- **Пробел** — держать для заряда пружины, отпустить для запуска
- **← / →** (или Z и /) — флипперы; можно держать и ловить шар
- **T** — толкнуть стол (три раза подряд — TILT, флипперы отключаются)
- На телефоне: касания левой/правой половины экрана и кнопка «Запуск»

## Правила

- Партия стоит 1 серебро. Кончилось — Джаспер жалует ещё.
- Очки: бамперы 100, слингшоты 50, банк целей 500 (+5000 за все три),
  огни Марни 200 (+1000 за все), штырёк 25.
- В конце партии очки и время превращаются в жетоны Марни —
  тратятся в лавке Джаспера (цены как в оригинале, вплоть до
  золотого слитка за 10 000).
- Рекорды и кошелёк хранятся в браузере.

Без зависимостей: HTML + CSS + чистый JS, один канвас.
